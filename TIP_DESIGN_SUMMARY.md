## Technical Details ⚙️

### Animations Used
1. `gentleGlow` - 3s infinite (box shadow pulse)
2. `shimmer` - 8s infinite (rotating gradient)
3. `pulse` - 2s infinite (heart icon scale)
4. `float` - 3s infinite (sparkles up/down)
5. `breathe` - 4s infinite on hover (gentle scale)

### CSS Techniques
- Gradients (linear, radial)
- Backdrop filters (blur)
- Pseudo-elements (::before, ::after)
- CSS animations (@keyframes)
- Transform & opacity (hardware-accelerated)
- Flexbox layout
- Media queries (responsive)

### Performance
- ⚡ **60fps** animations
- ⚡ **No images** (pure CSS)
- ⚡ **No JavaScript** required
- ⚡ **Lightweight** (< 5KB CSS)
